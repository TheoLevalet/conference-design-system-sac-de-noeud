EventCard assemble, elle n'invente rien 🧩

<button uiButton> : bouton natif, clavier et focus · uiCardMedia : attribut de placement · <ui-card-content> : composant conteneur

Emplacements Angular (ng-content) ≈ children en React ≈ <slot> en Vue et Web Components

⏱ 11:30 · Théo
Théo : « Le code d'EventCard : il importe des pièces du design system et les assemble. Tout le vocabulaire métier est ici : l'événement, « Complet », l'inscription. »
Wafa : « Pour l'action, on garde un vrai bouton HTML. uiButton est ici une directive de style du design system : elle habille le bouton sans remplacer son comportement natif. Pas besoin d'ajouter tabindex : le bouton est déjà accessible par Tab, et s'active avec Entrée ou Espace. Il faut aussi conserver un indicateur de focus visible. type="button" évite une soumission de formulaire involontaire. »
Théo : « Pourquoi uiCardMedia sans chevrons, mais ui-card-content entre chevrons ? Le premier est un attribut sur l'image native : la carte le repère avec ng-content select="[uiCardMedia]" pour la placer dans la zone média. Le second est un composant conteneur, repéré par son nom : ng-content select="ui-card-content". Ce sont deux sélecteurs de projection différents, pas deux façons d'écrire le même composant. »
Wafa (pour les non-Angular) : « Les emplacements, c'est l'équivalent de children en React ou des slots en Vue. »
