Une palette finie, nommée par sa valeur.

Wafa : « Première étape : on remplace les dix-sept bleus par une palette finie. Ce sont les tokens bruts : ils disent quelle valeur. »

Tokens sémantiques : des intentions 🎯

blue-100 → --color-primary-soft
blue-600 → --color-primary
blue-800 → --color-primary-strong

Les composants ne connaissent que la colonne de droite.

Wafa : « Le token sémantique dit pourquoi on utilise la couleur. Les composants ne devraient connaître que ceux-là. »
Théo : « Donc si je change un token, tout bouge ? »
Wafa : « Si tout passe par le sémantique, oui. Sinon, tu as dix-sept bleus. »

Le format DTCG : un alias relie l'intention à la valeur


{
  "color": {
    "blue": {
      "600": {
"$type": "color",
"$value": { "colorSpace": "srgb", "components": [0.15, 0.39, 0.92],
            "hex": "#2563eb" }
      }
    },
    "primary": {
      "$type": "color",
      "$value": "{color.blue.600}",
      "$description": "Actions principales, liens, focus"
    }
  }
}

Design Tokens Format Module, 1re version stable (2025.10). La séparation brut / sémantique est un usage, rendu possible par les alias.

Wafa : « Le Design Tokens Community Group a publié en octobre 2025 la première version stable du format. Il ne vous impose pas de couches, il vous donne le mécanisme : un alias, entre accolades, qui pointe vers un autre token. »
