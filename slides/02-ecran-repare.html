En CSS : un alias relie le sens à la valeur


:root {
  --red-600: #de1823;
  --color-primary: var(--red-600);
}

Ligne 2 : la valeur brute. Ligne 3 : le nom qui dit à quoi elle sert, relié à la valeur par un alias.

En CSS, var() illustre l'idée d'un alias. Le format DTCG définit aussi ses propres références entre tokens.

Wafa : « En CSS, le nom fonctionnel pointe ici vers une valeur de la palette : c'est une illustration du principe d'alias. Le format DTCG décrit les références dans son propre format d'échange. Les composants utilisent le nom fonctionnel ; un thème peut lui associer une autre valeur. »

Composant, recette ou cas unique ?

🏛️

Composant du design system

Générique et réutilisable dans les contextes où il convient, sans connaître le métier.

Ex. : Card, une boîte avec des emplacements. Rien de plus.

🍳

Recette

Une composition de composants du design system, utilisée de façon cohérente dans un produit, mais pas assez générique pour le design system. Souvent un organisme.

Ex. : EventCard

❄️

Cas unique

Un besoin ponctuel peut rester dans la fonctionnalité qui en a besoin.

Ex. : un bandeau ponctuel

Le niveau dit comment ça se compose. Le vocabulaire dit où ça vit.
