Component, recipe ou snowflake ?

🏛️

Design system component

Générique et réutilisable dans les contextes où il convient, sans connaître le métier.

Ex. : Card, une boîte avec des slots. Rien de plus.

🍳

Recipe

Une composition de design system components, utilisée de façon cohérente dans un produit, mais pas assez générique pour le design system. Souvent un organisme.

Ex. : EventCard

❄️

Snowflake

Un besoin ponctuel peut rester dans la fonctionnalité qui en a besoin.

Ex. : un bandeau ponctuel

Le niveau dit comment ça se compose. Le vocabulaire dit où ça vit.

Brad Frost, Design system components, recipes, and snowflakes. La dernière phrase : notre formulation.

Wafa : « Brad Frost propose un vocabulaire pour distinguer components, recipes et snowflakes. »
Wafa : « Un design system component est générique. Chez Frost, la Card est très simple : une boîte avec des slots. »
Wafa : « Une recipe compose ces components pour un contexte de produit. Un snowflake peut rester dans la fonctionnalité concernée ; il n'a pas besoin d'être promu. Notre carte d'événement est une recipe. »
Wafa : « Le niveau Atomic Design décrit comment ça se compose ; le contexte et le vocabulaire aident à décider où ça vit. Cette règle de décision est la nôtre, inspirée de Frost. »
